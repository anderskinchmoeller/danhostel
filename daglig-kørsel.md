# Daglig kørsel

## 1. Opdatér data
- [ ] Data → upload ny Arrivals / Rooms spec.-PDF fra Picasso. Medtag In-House; periode ca. 30 dage tilbage og 120 dage frem.
- [ ] Upload aktuelle konkurrentpriser, når der er nye observationer.
- [ ] Kontrollér events, grupper, blokeringer og manuelt låste priser.

## 2. Beregn og anvend priser
- [ ] Priser → Kør beregning. Kontrollér friskhed, advarsler og forslag.
- [ ] Kontrollér og godkend de priser, der skal bruges.
- [ ] Hent godkendte som CSV. Kopier gemmes i dagens_priser og skygge-v4-v5 ved download.
- [ ] Læg priserne ind i Picasso.
- [ ] Resultater → registrér faktisk indsatte priser, beregning, tidspunkt og eventuelle ændringer. Download er ikke bevis for anvendelse.

## 3. Afslut gårsdagens resultat
- [ ] Eksportér Hotelmanager (part 1 + 2) og Product Turnover for samme afsluttede opholdsdato, efter natkørslen.
- [ ] Resultater → upload rapporterne og kontrollér antal værelser og senge.
- [ ] Kontrollér opholdsdato, moms, morgenmad og totaler. Tilføj Accounts ved forskelle.
- [ ] Bekræft salgstal og afklaret omsætning særskilt. Lad uafklarede beløb stå åbne.
- [ ] Tilføj faktisk provision og variable omkostninger; ukendt er ikke nul.

## 4. Følg op
- [ ] Resultater → Graf og statistik / Økonomi: kontrollér afsluttede datoer og manglende data.
- [ ] Notér prisændringer, grupper, events og andre forhold, der kan forklare afvigelser.

## Når A/B-forsøget er startet
- [ ] Følg kalenderen pr. opholdsdato: A = receptionistens normale priser; B = modellens forslag.
- [ ] På A-datoer anvendes og vises modellens forslag ikke til receptionisten.
- [ ] Registrér faktisk anvendte priser og alle afvigelser. Gennemgå afsluttede blokke.
- [ ] Følg stopreglerne; vent med effektvurderingen til den aftalte slutanalyse.
